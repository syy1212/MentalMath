## 它能做什么

给孩子刷口算用的小工具：打开就刷，没有任何管控、密码和锁屏。**设备端只负责练习**（对齐 StudyOnTV 的被控端逻辑），题库管理全部在局域网网页完成。

- **开箱即刷**：首次启动自动生成 160 道内置题（20 以内加减 / 100 以内加减 / 表内乘除 / 两步混合各 40 道）
- **设备端**：大按钮「开始练习」+ 4 个口算档位；计时、连对、对错反馈与解析、每轮结算、历史最佳；练习记录（近 7 / 30 天）。看不到任何题库内容
- **家长管理页**（电脑/手机浏览器打开 `http://<设备IP>:8098/admin/`）：
  - **题库**：导入 JSON 文件、登记 URL 题库源（打开 app 时自动检查更新，默认 24 小时）、连接局域网里的 StudyOnTV 设备拉题、立即同步、删除
  - **设置**：每轮题数、**练习出题来源**（内置出题器或某个题库）、启用档位、自动同步间隔、深浅色主题
  - **记录**：近 7 / 30 天每天做题数、正确率、用时，只保存在设备上

## 小鲸鱼探险

- 答对一题收集 1 颗珍珠，完成整轮额外获得 2 颗；答错不扣珍珠
- 珍珠在整轮结束时保存，中途退出不发放本轮奖励
- 累计珍珠逐步点亮珊瑚湾、泡泡岛、海草森林、星光海、彩虹礁和鲸鱼乐园
- 勋章对应首次完成、连续答对 5 题、累计完成 50 题和整轮全对；同一勋章只提示首次获得
- 每日两轮小目标按设备练习记录计算，达成后优先提供休息入口，可自行继续练习

## 下载与更新

- **下载**：GitHub Releases 页获取最新 APK（`https://github.com/<你>/<仓库名>/releases/latest` 永远指向最新版）
- **更新**：新版本发布后，设备浏览器打开上面的链接重新下载安装即可，题库 / 记录 / 珍珠全部保留（同签名覆盖安装）
- **发布流程**见 [docs/release.md](./docs/release.md)（含国内网络备用通道与多设备说明）
- 成长收藏沿用设备端本地存储，兼容旧成绩；升级前的题量不会补发珍珠或满分勋章
- 管理页清空练习记录不会清空设备端收藏；清除应用数据会重置收藏

## 题库自动导入是怎么工作的

在管理页「题库」标签添加 URL 源（例如把题库 JSON 放在 GitHub / gitee / 群文件直链上），App 打开时对比上次同步时间，超过间隔就用 **整库替换** 的方式重新拉取——远端改了题，设备上跟着更新，不会越积越多重复题。

题库格式见 [docs/bank-format.md](./docs/bank-format.md)：既有省事的紧凑口算格式 `{"e":"12+7","a":19}`，也完全兼容 StudyOnTV 的题库 JSON（家长间流传的题库文件直接可用）。把格式文档发给 AI，就能让它批量出题。

导入后到「设置」标签把 **练习出题来源** 换成那个题库，孩子端「开始练习」就会刷它；保持「内置出题器」则永远有题可刷。

## 构建

```
cd app/native
./gradlew assembleDebug          # 调试包
./gradlew assembleRelease        # 签名包（需在 local.properties 配 KEYSTORE_*）
```

产物在 `app/build/outputs/apk/`，仓库根目录也放了一份当前版本。

- `local.properties`（不入库）：`sdk.dir` + `KEYSTORE_PATH` / `KEYSTORE_PASS` / `KEY_ALIAS` / `KEY_PASS`
- keystore 与 local.properties 一起备份，丢失后无法覆盖升级已安装的版本

## 架构

沿用 StudyOnTV 的设计逻辑（设备端答题、网页端管理），零第三方依赖：

```
App（WebView 宿主）
├── 设备端页面 /          # index.html：开始练习 + 口算档位 + 练习记录，无题库内容
├── 家长管理页 /admin/    # admin.html：题库 / 记录 / 设置 三标签（局域网浏览器访问）
├── 本地 HTTP 服务        # 8098 端口，无鉴权（家庭内网）
└── SQLite                # questions（bank_id 标来源）+ banks（题库源）+ events（练习记录）

练习链路：「开始练习」不带来源 → 服务端按配置的 practiceSource 出题（内置出题器或题库）；
         档位入口纯前端本地出题，离线可用
导入链路：文件 / 分享 / URL / 设备 → BankImporter 校验 → 事务整批入库（按源整库替换）
```

| 模块 | 说明 |
|---|---|
| `Generator.kt` | 4 档位出题，构造法保证结果合法（不出现负数、除法必整除） |
| `BankImporter.kt` | 校验与格式展开（紧凑格式 → 4 选 1），纯 JVM 可单测 |
| `LocalStore.kt` | SQLite 持久层，最小列 + details JSON |
| `BankSync.kt` | URL 拉取 + StudyOnTV 设备拉取（兼容旧版单次 50 条随机子集） |
| `LanServer.kt` | 手写 HTTP/1.1，无鉴权（纯刷题应用，家庭内网使用） |

## 说明

- 端口 8098，与 StudyOnTV 的 8099 不冲突，两个应用可装在同一台设备
- 本项目仅个人自用，题库与记录都保存在被控设备本地
- 灵感与架构来自 [StudyOnTV「题了个题」](https://github.com/chadyi/StudyOnTV)（Personal Use Only，本项目为其个人自用的延伸，不分发）
